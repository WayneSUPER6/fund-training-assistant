# 基金从业培训学习助手

一个供 AI 助手读取的学习辅助 Skill，适用于中国证券投资基金业协会基金从业人员远程培训系统。帮助学习者本人减少课程导航、播放控制和进度检查中的重复操作。

**测验由学习者自行作答和提交**。这是第三方社区项目，与中国证券投资基金业协会、WorkBuddy 或其他 AI 客户端无隶属或官方合作关系。

## 能做什么

| 功能 | 行为 |
| --- | --- |
| 课程导航 | 从个人中心点击课程卡片，只处理学习者指定的课程 |
| 播放控制 | 正常开始或恢复播放，按要求设置网站提供的倍速与音量 |
| 自动切换视频 | 当前视频正常播完且确认完整绿勾后，切换到下一段授权视频 |
| 课程进度核对 | 区分完整绿勾、部分完成圆点及课程总进度 |
| 跨课程衔接 | 全部视频、测验完成且课程为 100%／已完成后，进入下一门授权课程 |
| 故障恢复 | 区分短暂缓冲与故障，有限刷新、重进；支持用户指定的五分钟等待方式 |
| 学习内容辅助 | 解释概念、检索官方资料、梳理学习提纲和已提交错题的复习要点 |

自动切换在学习者本人观看时使用。学习者离开、暂停或停止时暂停播放；会话结束或工具失联后，不承诺后台继续执行。

## 测验与增量工作安排

AI 可以先查看测验的及格分、限时和剩余次数，然后交由学习者本人作答与提交。提交后，AI 再核对网站显示的成绩和完成标记。公开版不代选选项、不自动交卷、不提供在做测验的直接答案，也不附带题库。

使用过程中，你可以根据需要自行向 AI 追加增量工作安排，例如：

- “解释受托人义务与一般合同义务的区别，并列出公开资料依据。”
- “查询这个知识点对应的协会官方规定，给我原文链接。”
- “根据我已经提交的错题，整理相关知识点的复习提纲。”
- “接下来只检查课程进度，暂不播放新视频。”
- “暂停；我回来后再继续。”

AI 应按新增要求提供学习辅助，必要时说明资料和工具限制；追加任务不自动扩大为代答、代交卷或绕过平台限制的授权。

## 安装与使用

需要支持本地 Skill 和浏览器操作的 AI 客户端。纯聊天窗口或仅能搜索网页的工具不能直接控制培训页面。学习者应自行登录；不要把密码、Cookie 或验证码发给 AI。

### WorkBuddy

1. 下载本仓库 Release 中名称含 `workbuddy` 的 ZIP。
2. 在 WorkBuddy 的“专家·技能·连接器 → 技能 → 添加技能 → 上传技能”中导入。
3. 启用当前客户端提供的浏览器操作能力，确认 AI 能读取并正常操作你已登录的培训页面。
4. 按下面的例子指定课程，再开始学习。

WorkBuddy 包由同一份 `SKILL.md` 生成，并添加该平台要求的展示元数据。导入入口或校验要求可能随客户端版本变化，参考[官方技能文档](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)和[开放平台格式说明](https://open.workbuddy.cn/docs/skill)。

### 其他支持 Skill 的客户端

下载名称含 `standard` 的 ZIP，按客户端支持的方式安装其中的 `fund-training-assistant` 文件夹。Codex 界面元数据位于 `agents/openai.yaml`；其他客户端可忽略该文件。具体浏览器工具以客户端当前提供的接口和操作说明为准。

### 启动示例

```text
请使用 fund-training-assistant 辅助我本人学习。
我已登录基金从业人员远程培训网站。
只处理以下课程，并按顺序进行：
1. <我指定的课程名称>
2. <我指定的课程名称>
网站允许时可用 2.0×，音量按我的要求设置。
视频正常播完且确认完整绿勾后自动切换下一节。
遇到测验交给我自行作答和提交，之后再核对完成状态。
遇到持续网络故障，可关闭培训网页，五分钟后从个人中心重进一次；再次失败则停止并报告。
```

## 完成判断与使用边界

- 视频必须正常播放至结束，并出现完整绿色勾选。半绿色圆点、等待时间或百分比增加不能单独证明完成。
- 整门课程须全部视频和测验完整绿勾，并显示 100% 或“已完成”，才报告课程完成。
- 不跳进度、不伪造焦点或学时、不调用进度上报接口，不绕过验证码、登录或访问限制。
- 本仓库不包含课程视频、付费课件、试题答案、浏览器登录数据或个人学习记录。
- 学习辅助不等于平台对自动化操作的认可，也不保证培训学时认定。使用者须遵守平台当前要求；可参考[培训平台](https://peixun.amac.org.cn/)及[协会后续培训信息](https://www.amac.org.cn/fwdt/wyb/rygl/hxpx/hxpxzdjtz/)。

## 已验证范围

基础操作流程曾在支持浏览器控制的 AI 环境中用于正常播放、倍速、音量设置、完成标记核对、个人中心切换和有限故障恢复。公开版的学习者自行作答流程和 WorkBuddy 导入包尚未完成端到端实测；当前发布只完成结构、打包和隐私检查。

首次使用建议先验证一段完整视频的正常播放、绿勾和进度保存，再扩大课程范围。网页变化、账号权限、网络、电脑休眠或工具能力均可能影响连续操作。

## 从源码打包

只需 Python 3.10 或以上版本，无第三方依赖：

```text
python scripts/build_release.py --output dist
```

生成标准包、WorkBuddy 包、源码包和 SHA-256 校验文件。打包采用显式文件清单，不读取浏览器数据、个人配置或本机登录信息。
